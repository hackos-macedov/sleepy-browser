# Sleepy Browser

Минималистичный браузер для Windows 11 на Rust + WebView2 (`wry`).

## Что уже работает
- Стартовая страница в стиле приложенного скриншота: размытый серо-чёрный фон, часы, дата, погода-заглушка и поле поиска.
- Поиск через Google и переход по URL.
- Панель навигации поверх открытых сайтов: назад, вперёд, обновить, адресная строка и домой.
- Рендеринг сайтов через Microsoft Edge WebView2 Runtime.

## Требования
- Windows 10/11 x64.
- Rust toolchain: https://rustup.rs/
- Microsoft Edge WebView2 Runtime (обычно уже установлен в Windows 11).

## Запуск в режиме разработки
Открой PowerShell в папке проекта:

```powershell
cargo run
```

## Сборка .exe
```powershell
cargo build --release
```

Готовый файл будет здесь:

```text
target\release\sleepy-browser.exe
```

## Примечания
Это рабочий стартовый каркас, а не полноценная замена Chrome: пока нет вкладок, менеджера загрузок, закладок, истории, расширений, синхронизации и реального погодного API. Погода `14°` оставлена как визуальный элемент по референсу. Кнопка настроек пока показывает заглушку.
